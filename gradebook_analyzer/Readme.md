#Gradebook Analyzer 

#About

This is a small Python project to help analyze student marks. You can calculate average, median, highest, lowest marks, assign grades, see who passed or failed, and even save results to a CSV file.

#Features

1.Enter student marks manually or from a CSV file
2.Calculate average, median, highest, and lowest marks
3.Assign grades automatically (A, B, C, D, F)
4.Show grade distribution
5.List passed and failed students
6.Display results in a table
7.Export results to CSV
