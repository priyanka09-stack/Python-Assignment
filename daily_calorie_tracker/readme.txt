#Daily Calorie Tracker 
#About the Project
This is a Daily Calorie Tracker project made using Python. 
It is a simple Command Line Interface (CLI) application that helps users track their daily calorie intake.
It can help you check if you are eating under, over, or within your daily calorie limit.

#Features

1.Input number of meals you eat in a day.
2.Enter meal names and their calories.
3.Calculate total calories and average calories per meal.
4.Compare your total calorie intake with your daily calorie limit.
5.Show results in a neat table format.
6.Option to save your daily session to a text file with timestamp.
